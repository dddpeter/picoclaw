## 1. 卡片本地态保持（任务 1，25a47e3e）

**问题**：二期 A2uiCard 用 `useMemo([ui.messages])` 全量重建 MessageProcessor——流式增量到达时所有控件元素重挂，用户未提交的表单输入丢失。

**方案**：processor 常驻（useRef）+ 增量喂帧：
- ui.messages 变化 → 与已处理帧逐帧 JSON 指纹比对 → 首分歧帧起重播（slice）
- 三重建触发：① processor 不存在；② 分歧窗口含 createSurface（重 create 接管，按 surfaceId 取最后一次 create 起的帧折叠——与 Go 侧 RenderUIHistoryFold 语义对齐）；③ surfaceId 变化
- 兜底：增量 processMessages 抛错 → warn 一次 + 全量重建一次；再失败 → 占位
- dispose 四路径：卸载/重建/兜底/buildFrom 抛错

**关键发现（纠正计划假设）**：pico 合并广播的语义不是"新帧尾部 append"——同 path 的 updateDataModel 帧**原地覆盖**（last value wins，批长不变，pico.go mergeA2UIFrames）。纯尾部增量会静默丢覆盖型更新。解决：逐帧指纹 + 首分歧重播，对 append/覆盖两种形态都收敛（pico_test.go 钉死覆盖语义）。

**live 验证**（kimi-webbridge）：渲染 → fill 输入 → 模型发增量（不含该 path）→ 输入值完整保留。
**已知边界**：模型若把增量写到绑定 path 的祖先（部分对象覆盖子树）→ 绑定值被合理清空（非 bug，见 §3 教学修复）。

## 2. 交互体验补齐（任务 2，5955d05b）

- **发送失败反馈**：sendChatMessage false（WS 断连）→ 卡内提示（i18n 五语言 a2uiSendFailed）+ 3s 冷却；handler 冷却拒绝是唯一漏斗（Lit 按钮无法逐个 disabled）。照抄 ask-card submitting 模式，30s→3s（A2UI 动作无服务端回执）。
- **过期卡防错位**：turns.ts latest 标记循环扩到 a2ui（每会话最近一张为 latest）；非最新卡动作被 handler 拦截 + 提示（i18n a2uiStaleCard）。默认 latest=true（标记循环失效时退回现状全可点，软危害）。
- **插值转义**：surfaceId/name/sourceComponentId JSON.stringify（无引号无换行无反斜杠的 id 逐字节兼容旧格式）。
- 已知边界：同 chat 双 live 卡并存时旧卡会被拦+提示（per-surfaceId 精化留升级路径）。

## 3. description 压缩 + 配置开关（任务 3，08ebe13e + d7513826）

- **压缩**：7035B → 3139B（-55%）。SchemaContract 全部 18 条锁定短语语义保留（逐条核对），删的是措辞冗余、5 组件大示例（压成 3 帧最小示例）、available components 清单（门错误信息动态生成）。**3200B 上限断言**锁进 SchemaContract 防回胀。
- **压缩地板裁决**：剩余内容全部是事故教学（5 次实测事故的 props/形状教学），再删引发模型重试反噬——3.1KB 即地板。
- **开关**：`tools.render_ui`（*bool，nil=on 开放默认惯例）→ IsToolEnabled 显式 case → false 时从 agent 注册表移除。config 两态测试。
- **live 发现补教学**（d7513826）：模型把增量写到 /prefs（部分对象）抹掉 /prefs/note——updateDataModel value 按 path 整子树替换，description 补"写到最深路径保兄弟键"。

## 4. 视觉进阶（任务 4，f3b79f7a + 8af432e9 + cc226322 + b6a8f9e5）

- **VegaChart 主题联动**：MutationObserver 监听 html class（主题开关）→ 防抖 300ms → themeVersion bump → normalizeVegaSpec 重跑（重新读 --primary）→ 重嵌。
- **卡面渐变深化**：主色顶光 + 对角次色呼吸 + 88% 半透明（纯 background）。
